ВЕРСИЯ С НАТИВНЫМ СКАЧИВАНИЕМ

Кнопки скачивания — обычные HTML-ссылки с атрибутом download.
JavaScript не перехватывает нажатие и не открывает картинку вместо загрузки.

1. Распакуй архив.
2. Добавь фото в verloren_img.
3. Запусти Обновить_список_фото.bat, чтобы создать photos.js.
4. Замени файлы сайта на GitHub этой версией и загрузи папку verloren_img.
5. Commit & Push, затем открой опубликованный GitHub Pages и нажми Ctrl+F5.

ОГРАНИЧЕНИЕ:
Атрибут download работает для файлов с того же origin (GitHub Pages — тот же сайт).
Если фото перенаправляет на отдельный домен/CDN или URL ведёт на другую площадку,
браузер может проигнорировать download из-за ограничений безопасности. На GitHub Pages
нет возможности выставить HTTP Content-Disposition: attachment для отдельных файлов.
